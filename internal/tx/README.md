# internal/tx

This directory holds all TX control code of auto7.

TX control is code that can make WSJT-X or MSHV transmit.
TX control is also code that decides the time at which auto7 can ask for a transmission.
The arm logic and the presence logic are examples.

Put all TX control code in this directory. Do not put it in other directories.

The operator must approve each change in this directory before the commit.
